# AgilityShift Dashboard

This is the interactive frontend dashboard for AgilityShift PQC Migration reports.

## Installation

```bash
npm install
```

## Running the Dashboard

Start the local development server:

```bash
npm run dev
```

## Building

```bash
npm run build
```

## Data

The dashboard currently loads `src/data/sample-report.json`. 
In future phases, it can dynamically load `agilityshift-report.json` generated by the Python CLI.
