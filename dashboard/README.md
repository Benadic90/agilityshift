# AgilityShift Dashboard

A local React/Vite visualization dashboard for analyzing AgilityShift PQC Migration Reports.

## Features
- **Zero Backend**: Operates entirely locally off the `sample-report.json` generated by the CLI.
- **Severity Triage**: Interactive views for Critical, High, and Medium vulnerabilities.
- **PQC Readiness Score**: Clean, enterprise-grade metrics dial.
- **AI/Template Explanations**: Deep, human-readable context on why each finding will break in a post-quantum world.

## Running Locally
```bash
npm install
npm run dev
```

Then visit `http://localhost:5173` in your browser.
